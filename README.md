# Snavi

Snavi is a [navi](https://github.com/denisidoro/navi)-like interactive command-line cheatsheet tool but with **s**tructured cheat file and C**S**harp support.

Check `sample-cheats` for samples. It could be run with:

```sh
dotnet Snavi.dll run -c git/commit.json -c git/checkout.json -c cat/cat.json
```
